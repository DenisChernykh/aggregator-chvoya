# Mover — перенос DOM-элементов по брейкпоинту

## Описание

`Mover` переносит элемент из исходного места в целевой контейнер при выполнении условия (по умолчанию — ширина окна ≤ `breakpoint`).
Элемент возвращается назад при обратном условии. Для восстановления исходного положения используется плейсхолдер.

## Разметка

- Элемент, который нужно переносить: `data-move-to=".example .item"` (конкретное место в DOM).
- Перемещение зависит от атрибута: `data-move-before`, `data-move-after`, `data-move-prepend`, `data-move-append`, `data-move-to`.
- Необязательный брейкпоинт для элемента: `data-move-max="1199"`, можно указать и минимальный `data-move-min="767"`, по умолчанию до 768.
- Если при переносе нужно обернуть элемент в другой класс - можно добавить `data-move-wrapper="classname"`, после переноса элемент будет внутри div блока с классом `classname`.

Пример:

```html
<header>
  <nav data-move-to=".mobile-panel"></nav>
</header>

<!-- Целевой слот для мобильного размещения -->
<div class="mobile-panel"></div>
```

## Инициализация

- Автоматическая: при наличии на странице `[data-move-to]` и т.д., библиотека инициализируется в общем бутстрапе.
- Ручная:

```js
import { initMovers } from './initMovers'

const movers = initMovers()
```

## Поведение

- В исходном месте создается плейсхолдер `<div data-move-placeholder>` для корректного возврата.
- При активном состоянии элемент аппендится в указанный контейнер по классу, в то место, куда указан дата-параметр (append, after, prepend, before).
- При изменение разрешения окна пересчитывается условие и выполняется перенос/возврат.

## Рекомендации

- Используйте вложенные классы для каждого независимого перемещения (.products\_\_grid .product-item), чтобы избежать перемещения в одинаковый класс.
