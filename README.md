# Хвоя — сайт загородного отеля

Многостраничный интерфейс отеля: знакомство с территорией и услугами, выбор номера, просмотр галерей, предложений и статей, обращение по поводу бронирования. Проект включает HTML-шаблоны, JavaScript-поведение, SCSS и сборку на Vite.

## Возможности

- Главная страница, список публикаций, отдельная статья и страница 404.
- Карточки номеров, галереи, истории с фото/видео, отзывы и раскрываемые блоки.
- Модальные окна номера, отзыва и заявки, маски ввода и состояния формы.
- Мобильная навигация, перенос элементов по брейкпоинтам и ленивая загрузка видео.
- Разделение цветовых токенов Figma на globals/semantic и генерация SCSS-переменных.
- Браузерные проверки адаптивных секций, форм и динамического контента.

## Что показывает проект

Разработку насыщенного контентом интерфейса с переиспользуемыми секциями и адаптивным поведением. Разметка собирается из частичных шаблонов, интерактивные модули подключаются по наличию элементов на странице, а визуальные решения связаны с дизайн-токенами. Это применимо к сайтам гостиниц, сервисным сайтам, CMS-вёрстке и работе с дизайн-системами.

## Разработка

Node.js 24, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
```

```sh
pnpm build
pnpm test:e2e
```

Vite собирает все HTML-страницы в `build/` и раскрывает `@@include` из каталога шаблонов. Тесты используют Playwright и локальный сервер. Для подготовки браузеров выполните `pnpm exec playwright install chromium webkit`.

После изменения экспортированных Figma-токенов:

```sh
pnpm tokens:split -- assets/tokens.figma.json --global-mode=Хвоя --semantic-mode=light
pnpm tokens:build-css
```

Общий модуль историй поставляется в `packages/reels` и устанавливается как локальная зависимость вместе с проектом.
