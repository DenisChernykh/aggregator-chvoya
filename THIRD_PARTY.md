# Сторонние компоненты

## Reels Module

`packages/reels` содержит поставляемый пакет `modules-vg-reels` версии 1.0.1. Автор: Маслаков Владислав Денисович. Источник: https://github.com/VICTORY-digital/modules-vg-reels (ветка npm-package). Авторство и документация пакета сохранены.

Пакет подключён локально через `file:packages/reels`, чтобы установка проекта воспроизводилась вместе с этой версией модуля. Он предоставляет интерфейс историй и использует общий Swiper проекта. Остальные внешние зависимости устанавливаются через pnpm.
